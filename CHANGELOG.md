# Changelog

## 0.1.0 - Unreleased

- Initial provider with assistant, workflow, and skill resources.
- OAuth 2.0 client-credentials authentication.

## 0.1.1 - Unreleased
- Added skill create/update/delete support


## 0.1.2 - Released
- Added support for hydrated companion files in skill details.

## 0.2.1 - Released
- Fixed inconsistent workflow state after API updates by allowing refreshed JSON graph fields and guardrail assignments to be recorded.

## 0.3.0 - Released
- Added user- and project-scoped integration resources for Webhook, MCP, Scheduler, Jira, OpenAPI, and Git, including import support.
- Added an integration module, examples, and documentation.

## 0.3.1 - Unreleased
- Documented the required resource type and ID for webhook integrations.
